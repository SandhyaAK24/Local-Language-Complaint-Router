# 🤖 ComplaintAI — AI-Powered Local-Language Complaint Router

> An AI-powered civic complaint management system that allows users to submit complaints in their preferred local language and intelligently routes them to the appropriate department.

**Project Type:** Full-Stack Web Application  
**Frontend:** React.js  
**Backend:** Python / Django  
**Database:** MySQL / PostgreSQL  
**AI/ML:** Language Detection, Translation, Complaint Classification & Priority Detection

---

## 🌟 Overview

ComplaintAI is designed to make civic complaint reporting easier for people who are more comfortable communicating in regional and local languages.

The system accepts a complaint in a user's preferred language, analyzes it using AI, translates it into English, identifies the appropriate government/service department, and assigns a priority level.

## 🔄 How It Works

```text
User submits complaint
        ↓
Language Detection
        ↓
Complaint Translation
        ↓
Complaint Understanding / Classification
        ↓
Department Identification
        ↓
Priority Detection
        ↓
Complaint Routed to Appropriate Department
        ↓
User tracks complaint status
```

## 👥 User Workflow

1. Create an account or log in.
2. Submit a complaint in a preferred language.
3. ComplaintAI detects the language.
4. The complaint is translated into English.
5. The system identifies the relevant department.
6. AI determines the complaint priority.
7. The complaint is routed for further action.
8. Users can track their submitted complaints.

## 🧑‍💼 Admin Workflow

Administrators can:
- View submitted complaints.
- Review AI-classified complaints.
- Monitor complaint status.
- Identify assigned departments.
- Manage complaint resolution workflow.

## 🎯 Problem Statement

Many citizens face difficulties while reporting civic issues because complaint systems may primarily support English or a limited number of languages.

ComplaintAI aims to reduce this language barrier by allowing users to communicate naturally in their preferred language while using AI to understand, translate, classify and route their complaints.
